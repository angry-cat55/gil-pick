# 길픽 MVP 정의

## 1. 제품 목표

길픽은 여행 중 혼잡도, 날씨, 운영시간 변화에 맞춰 남은 일정의 대체 장소와 경로를 제안하는 Android 여행 일정 관리 서비스다.

## 2. MVP 범위

### 사용자와 여행

- 카카오 로그인
- 여행 생성·조회·수정·삭제
- 여행명 2~30자, 같은 이름 허용, 여행 기간 최대 7일
- 여행 상태: KST 기준 시작일 전 `예정`, 여행 기간 내 `여행 중`, 종료일 후 `완료`
- 여행 목록은 무한 스크롤로 제공하며 여행 중, 시작일이 가까운 예정, 종료일이 최근인 완료 순으로 표시
- 여행명 검색과 상태 필터

### 일정과 경로

- TourAPI 기반 장소 검색·상세 조회
- 날짜별 장소 추가, 순서·체류시간·이동수단 편집
- 카테고리 추천 체류시간 자동 입력 및 30분 단위 증감
- 추천값: 자연 120분, 문화·역사 90분, 음식 60분, 카페 60분, 쇼핑 90분, 기타 60분
- 체류시간 범위 30~360분
- 도보·자동차는 TMAP, 대중교통은 ODsay로 경로 계산
- Naver Map SDK로 지도와 경로 표시

### 당일 여행 진행

- 사용자가 `오늘 여행 시작`을 누른 서버 수신 시각을 `actualStartedAt`으로 저장
- 현재 위치를 확보하면 첫 장소 ETA의 기준점으로 사용하고, 없으면 장소 간 계획 경로로 ETA 계산
- 위치 권한이 없거나 정확도가 부족해도 수동 도착·출발로 진행 가능
- 다음 장소 300m 이내에서 5분 DWELL 시 도착 후보 생성
- 도착 알림에 5분간 무응답이면 자동 도착, 자동 확정 후 5분간 되돌리기 제공
- `아직이에요` 선택 시 10분 후 한 번만 재알림하며 장소별 알림은 총 2회로 제한
- `다음 장소로 출발` 버튼은 즉시 출발 확정
- 현재 장소 400m 밖 EXIT 시 출발 후보 생성, 5분간 무응답·무재진입이면 자동 출발
- 자동 출발 후 5분간 되돌리기 제공
- `아직 머무는 중` 선택 시 해당 장소 자동 출발 감지 중단
- 가까운 다음 장소에서 DWELL이 발생하면 이전 장소 완료와 다음 장소 도착을 하나의 전환으로 처리
- 마지막 장소 도착 확정 시 당일 일정 완료, ETA·경로 재계산·변수 감지·지오펜스 종료

### 변수 감지와 대체 장소

- 진행 중인 남은 일정을 10분마다 평가
- 혼잡도, 날씨, 운영시간을 ETA 시점 기준으로 판단
- 대체 후보는 기존 장소 기준 0.5km에서 찾고, 없으면 1km와 2km까지 확장
- 거리 35%, 베이지안 보정 평점 30%, 혼잡 20%, 날씨 15%로 점수화
- 누락 변수는 제외하고 나머지 가중치를 100%로 재정규화
- 운영 종료 장소는 제외하고 상위 10개를 제공
- 후보 선택 후 경로 미리보기를 확인해야 일정에 반영
- 변경 후 30초까지 되돌리기 제공
- 장소 변경 제안 알림 전체 ON/OFF

## 3. MVP 제외

- 이메일 회원가입, 구글·네이버 로그인
- 한국관광공사의 관광지 집중률·지역별 관광 수요 관련 추가 API
- 사용자별 혼잡·날씨·운영시간 임계값 조절과 설정 초기화
- 서버 캐시, Redis, Celery, 분산 작업 중복 방지
- 비동기 경로 계산 작업 조회
- 모든 기기 일괄 로그아웃
- 삭제한 여행 복구와 자동 물리 삭제

## 4. 성공 조건

- 사용자가 여행과 날짜별 일정을 만들고 실제 경로를 확인할 수 있다.
- 여행 시작 후 장소 도착·출발·건너뛰기를 수동 또는 자동 감지로 처리할 수 있다.
- 진행 상태가 바뀌면 남은 일정의 ETA가 일관되게 갱신된다.
- 방문하기 어려운 장소가 감지되면 운영 가능한 대체 장소와 변경 경로를 확인하고 선택할 수 있다.
